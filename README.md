# tizenbrew-tvwall

Модуль [TizenBrew](https://github.com/reisxd/TizenBrew): открывает на телике
Samsung страницу заставки с домашнего сервера — живые обои по кругу, часы,
дата. Любая кнопка пульта закрывает заставку.

Здесь только ярлык: адрес страницы в `package.json` (`websiteURL`).
Сама страница и видео лежат на сервере в домашней сети и сюда не попадают.

Добавить в TizenBrew: Module Manager → Add GitHub module → `JJKenn3dy/tizenbrew-tvwall`.
